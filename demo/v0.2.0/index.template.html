One masked residue per example; the model scores the residue that actually occurs. The fixed panel has 6,305 scored standard residues. At batch size 16 within each sequence, the prepared workload has 415 scoring forwards, partitioned 208/207 across two independent GPU shards. Warm-up and pilot calls are counted separately.
