## Files and use

- `input_sequences.fasta`: 30 sequence-distinct provisional natural OspC proteins, untrimmed, 207–214 aa.
- `sequence_metadata.tsv`: accession, organism, supplied strain with provenance, reference strain comments, source URL, retrieval date, sequence hash, selection criteria and flags. Blank strain means unresolved/missing; multiple reference strains are not silently assigned.
- `source_data/proteome.fasta` and `proteome_annotations.tsv`: UP000001807 B31 canonical proteome, 1,291 matching accessions. `proteome.json` retains verification metadata and genome references.
- `source_data/ospc_candidates.json` and `candidate_quality.tsv`: original 500-record candidate page and all exclusion/duplicate flags. The page is deliberately bounded and not exhaustive; panel composition is not a population-frequency estimate.
- `reference_structures/`: 1GGQ and 1G5Z CIF coordinates and metadata, explicitly pre-existing experimental references. `reference_summary.json` includes construct, sequence mapping, refinement and assembly fields. Neither structure was generated by this project.
- `evidence/`: primary bibliographic records, license policies, and the CC BY 4.0 open-access primary study DOI 10.1128/mbio.02981-22 (PMC10128040 HTML). Attribute UniProt and article authors when reusing the evidence; preserve supplied DOI/PMID attribution. Other full texts are not included merely because citations exist.
- `runtime_inventory.json`, `source_manifest.json`, `data_quality_report.md`: observations, provenance, hashes, limits and blockers.
- `scripts/`: preparation and inventory source for review. Downloader requires public network access and re-fetches inputs; do not run it just to unpack the bundle. The preparation script uses Python standard library only.
